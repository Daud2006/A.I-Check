# Menyalakan A.I-Check

Untuk membuka website dan menggunakan Deteksi Gambar, buka dua jendela
PowerShell biasa. Jalankan satu blok di setiap jendela.

## Terminal 1 — Nyalakan AI Engine

Salin blok ini ke PowerShell pertama. Tunggu sampai muncul
"Application startup complete". Biarkan terminal ini terbuka.

```powershell
Set-Location -LiteralPath 'C:\laragon\www\A.I-Check'
$detectorPython = (Resolve-Path '.\aidetect-engine\.venv-aidetect\Scripts\python.exe' -ErrorAction Stop).Path
$env:HF_HOME = (Resolve-Path '.\aidetect-engine\.hf_cache' -ErrorAction Stop).Path
$env:HF_HUB_OFFLINE = '1'
$env:AIDETECT_MODEL_DIR = (Resolve-Path '.\aidetect-engine\models_permissive' -ErrorAction Stop).Path
$env:AIDETECT_OPERATING_POINT = 'fpr5'
$env:AIDETECT_THREADS = '4'
$env:AIDETECT_MAX_BYTES = '10485760'
$env:AIDETECT_MAX_FILES = '1'
& $detectorPython -m uvicorn aidetect.api:app --app-dir '.\aidetect-engine' --host 127.0.0.1 --port 8766 --workers 1
```

## Terminal 2 — Nyalakan website

Salin blok ini ke PowerShell kedua. Website, worker, dan scheduler akan
menyala bersama. Tampilan memakai aset yang sudah dibangun.
Biarkan terminal ini terbuka.

```powershell
Set-Location -LiteralPath 'C:\laragon\www\A.I-Check'
$env:Path = 'C:\laragon\bin\php\php-8.3.30-Win32-vs16-x64;' + $env:Path
composer run start:local
```

Buka http://127.0.0.1:8000 di browser. Untuk berhenti, tekan Ctrl+C di
masing-masing terminal.

Jika diminta membuat aset, jalankan npm.cmd run build dari folder proyek,
lalu jalankan kembali composer run start:local.

Untuk setup awal atau pengujian tambahan, lihat README.md.
