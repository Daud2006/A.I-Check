# Panduan menjalankan A.I-Check

Detector memproses gambar secara lokal. Jangan tutup terminal detector atau
worker selama pemeriksaan berlangsung.

## Persiapan pertama kali

1. Buka PowerShell di folder proyek `C:\laragon\www\A.I-Check`.
2. Siapkan Python dan unduh model. Langkah ini cukup dilakukan sekali:

   ```powershell
   Set-Location .\aidetect-engine
   if (-not (Test-Path .\.venv-aidetect\Scripts\python.exe)) {
       py -3.12 -m venv .venv-aidetect
   }
   $python = Resolve-Path .\.venv-aidetect\Scripts\python.exe
   $env:HF_HOME = Join-Path (Get-Location) '.hf_cache'
   $env:HF_HUB_DOWNLOAD_TIMEOUT = '600'
   & $python -m pip install -e '.[api]'
   & $python scripts\fetch_models.py --ensemble-only --model-dir models_permissive
   Set-Location ..
   ```

   Tunggu sampai perintah selesai sebelum menutup PowerShell.

## Setiap kali ingin memakai checker

1. **Perbarui database jika proyek baru diperbarui.** Di PowerShell pada folder
   proyek, jalankan:

   ```powershell
   php artisan migrate
   ```

   Jika tertulis `Nothing to migrate`, lanjut ke langkah berikutnya.

2. **Nyalakan detector.** Buka PowerShell baru pada folder proyek, jalankan:

   ```powershell
   $python = Resolve-Path .\aidetect-engine\.venv-aidetect\Scripts\python.exe
   $env:HF_HOME = (Resolve-Path .\aidetect-engine\.hf_cache).Path
   $env:HF_HUB_OFFLINE = '1'
   $env:AIDETECT_MODEL_DIR = (Resolve-Path .\aidetect-engine\models_permissive).Path
   $env:AIDETECT_OPERATING_POINT = 'fpr5'
   $env:AIDETECT_THREADS = '4'
   $env:AIDETECT_MAX_BYTES = '10485760'
   $env:AIDETECT_MAX_FILES = '1'
   & $python -m uvicorn aidetect.api:app --app-dir .\aidetect-engine --host 127.0.0.1 --port 8766 --workers 1
   ```

   Biarkan PowerShell ini tetap terbuka. Jangan jalankan perintah detector lagi
   di terminal lain.

3. **Pastikan detector siap.** Di PowerShell ketiga, jalankan:

   ```powershell
   Invoke-RestMethod http://127.0.0.1:8766/health
   ```

   Lanjut hanya jika hasilnya menunjukkan `status: ok` dan
   `models_loaded: True`.

4. **Jalankan website, worker antrean, dan Vite.** Jika website di
   `http://127.0.0.1:8000` belum berjalan, buka PowerShell baru pada folder
   proyek, lalu jalankan:

   ```powershell
   composer run dev
   ```

   Biarkan terminal ini terbuka. Perintah tersebut menjalankan Laravel,
   worker analisis, dan Vite. Pail tidak dijalankan karena tidak mendukung
   Windows.

   **Jika website port 8000 sudah berjalan**, jangan jalankan `composer run dev`
   lagi. Periksa terminal yang menjalankan website: jika belum ada pesan
   `Weighted analysis worker berjalan`, buka PowerShell baru di folder proyek
   dan jalankan worker saja:

   ```powershell
   php artisan analyses:work
   ```

   Biarkan terminal worker terbuka. Jalankan hanya satu worker.

5. **Periksa gambar.** Buka `http://127.0.0.1:8000/checker`, masuk ke akun,
   pilih gambar, lalu tekan tombol periksa. Tunggu hingga hasil deteksi muncul.
   Akun dengan role **admin** memiliki kuota tanpa batas; kuota akun biasa
   mengikuti batas paketnya.

## Jika status terus menunggu

1. Pastikan terminal detector masih terbuka dan `/health` menunjukkan model
   siap.
2. Pastikan satu terminal worker masih menampilkan
   `Weighted analysis worker berjalan`.
3. Pastikan migrasi sudah dijalankan dengan `php artisan migrate`.
4. Jangan menyalakan worker kedua. Setelah layanan aktif, muat ulang halaman
   checker dan coba kembali.

Untuk menghentikan layanan, tekan **Ctrl+C** pada terminal yang menjalankan
detector, worker, dan website.
